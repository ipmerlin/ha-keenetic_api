# 1.4b2: отправка SMS только через устройство с модемом

- Одно notify-действие на каждый физически подключённый модем.
- Удалённые интерфейсы MwsMobile на контроллере Mesh исключены из SMS.
- Убрано общее действие роутера, дублировавшее действие модема.
- В «Форме ввода» появились поля «Текст SMS» и «Номер получателя».
- Сохранены номер по умолчанию, входящие сообщения, события и ручная отметка прочтения.

При обновлении с 1.4b1 замените общее действие роутера в автоматизациях на
действие нужного модема. Уже используемые действия физических модемов
сохраняют свои имена. Для применения обновления перезапустите HA.
