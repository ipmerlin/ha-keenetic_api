# 1.4b1: SMS для модемов Keenetic

- Сенсор непрочитанных SMS для каждого поддерживаемого модема.
- Только последнее полное сообщение в атрибутах; частичный текст скрыт.
- Событие keenetic_api_sms для нового полностью полученного сообщения.
  Сообщения исходного снимка при запуске событий не создают.
- Действия keenetic_api.list_sms и keenetic_api.mark_sms_read.
- Отправка через отдельные notify-действия модемов и общее действие роутера.
- Номер по умолчанию в настройках, переопределение через target.
- Опрос не помечает SMS прочитанными. При тайм-ауте отправка не повторяется.

Предварительный выпуск: SMS на реальном оборудовании ещё не проверены.
Примеры действий и полное описание — в README.
