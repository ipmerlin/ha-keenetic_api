# 1.2.5b6: динамические иконки сигнала и устранение дублей

Иконки RSSI, RSRP, SINR и RSRQ меняются по значению, как в пользовательском
шаблоне. Пороги RSSI/RSRP/RSRQ сохранены. Для SINR большему значению
соответствует лучшая индикация. Несуществующие antenna-with-spike и
speedometer-fast заменены иконками из MDI. Отсутствующие данные не
подменяются нулём; используется signal-off. Оператор: radio-tower.

Включено исправление дублей из b5: при наличии прежних интерфейсных
датчиков не создаются повторные счётчики трафика, скорости и подключение.
Удаляются только повторные записи b4 с подтверждённым исходным датчиком
той же записи HA. Исходные entity_id и история в базе сохраняются.
На ретрансляторах, где прежних датчиков не было, новые остаются.

48 тестов, включая граничные значения иконок, смену состояния, неизвестный
сигнал, сохранение идентификаторов и безопасное устранение дублей.

Обновитесь через HACS до v1.2.5b6 и перезапустите Home Assistant.
Авторизацию, записи роутеров и пользовательские шаблоны менять не нужно.
