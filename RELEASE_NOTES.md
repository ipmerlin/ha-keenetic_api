# 1.2.5b2

Добавлена необязательная авторизация токеном KeeneticOS 5.2 и перенастройка
существующей записи без удаления сущностей. Сохранён вход по паролю для старых
прошивок. Токен передаётся заголовком, не попадает в URL и отладочные сообщения;
при отказе токена вход по паролю не выполняется.

Исправлены падения при отсутствующих данных о прошивке и устаревший импорт
ScannerEntity. Изменения перенесены поверх исходного проекта с сохранением его
дополнительных платформ и функций.

Проверки: 20 локальных тестов с подставными HTTP-ответами и объектами HA,
проверка синтаксиса Python. Реальная работа токена через LAN, полный запуск
Home Assistant, обновление прошивки и скачивание резервной копии не проверены.

Установка и ввод токена описаны в README. Архив keenetic_api.zip содержит файлы
интеграции без дополнительной верхней папки; распакуйте его в
/config/custom_components/keenetic_api/ и перезапустите Home Assistant.
